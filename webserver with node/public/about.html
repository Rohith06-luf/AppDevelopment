Project Architecture

About the Web Server

This project demonstrates how Node.js and Express.js process HTTP GET and POST requests, validate form payloads server-side, and implement HTTP status codes cleanly.

Core Implementation Highlights

📁

Static File Middleware

Uses express.static('public') to serve CSS, JavaScript, and static HTML files effortlessly.

⚡

Post / Redirect / Get

Handles form submission on POST /contact, performs validation, and uses HTTP 303 redirect to prevent duplicate submissions.

🛡️

Server-Side Validation

Validates name length (1-100), email pattern & length (max 254), and message length (1-2000) before approving requests.

🚫

Custom 404 Middleware

Catches all unhandled routes using a fallback middleware that returns an HTTP status code 404 with custom markup.
